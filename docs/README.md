## Contribuir a la Documentación

Cuando agregues nueva documentación:

1. **Ubicación apropiada**: Coloca los archivos en la carpeta correcta según su propósito
2. **Formato consistente**: Usa Markdown con estructura clara
3. **Fecha de actualización**: Incluye la fecha de última actualización
4. **Enlaces internos**: Actualiza este README con enlaces a nuevos documentos

## Convenciones

- **Nombres de archivo**: Usa kebab-case (palabras-separadas-por-guiones)
- **Formato**: Markdown (.md)
- **Idioma**: Español para documentación interna
- **Estructura**: Usa headers jerárquicos (# ## ###)
